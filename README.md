Школьный Помощник: чат-бот для MAX

Чат-бот для мессенджера MAX. Помогает школьникам 7–11 классов быстро найти материалы для проекта, подготовиться к контрольной по плану и не забыть о дедлайнах.

**Команда:** «Саб-лимонад»
**Направление:** «Подземелье знаний»
**Организация:** КГБУДО «Камчатский центр детского и юношеского технического творчества»
**Бот в MAX:** https://max.ru/ideya_fiks_121_bot

## Возможности

### Материалы для проекта
Ученик пишет тему, например «Физика — Электричество в быту». Бот присылает одно сообщение с вкладками:
- Структура: актуальность, цель, задачи, гипотеза, главы;
- Источники: проверенные ресурсы (РЭШ, БРЭ, КиберЛенинка и др.);
- Слайды: план презентации по слайдам;
- Идея: что сделать в практической части.

### План подготовки
Ученик пишет «Осталось 3 дня до математики». Бот составляет план по дням и часам:
- дни листаются кнопками;
- есть чек-лист с отметками и шкала прогресса;
- план можно завершить (он уйдёт в архив) и вернуть обратно.

### Дедлайны
Можно писать обычным языком:
- «Послезавтра проект по физике»
- «15.11 в 18:00 сдать доклад»
- «В пятницу контрольная по химии»

Ещё дедлайн можно добавить через кнопку «Дедлайн». Цвет показывает срочность: 🔴 сегодня или завтра, 🟠 до 3 дней, 🟢 больше.

###  Напоминания
| Когда | Что приходит |
|---|---|
| Через 2 и 4 часа после создания плана | «Как подготовка?» и прогресс |
| Каждый день плана в 15:30 | задачи на сегодня |
| Накануне в 19:00 | «Завтра дедлайн / контрольная» |
| В день Х в 08:00 | «Сегодня дедлайн», пожелание удачи |
| За 2 часа (если указано время) | «Осталось 2 часа!» |

В напоминаниях есть кнопки «Готово» и «Через час».

### Часовой пояс ученика
При первом запуске бот спрашивает, сколько у ученика сейчас на часах, и по ответу определяет часовой пояс. Пояс можно выбрать и кнопкой с городом. Все дедлайны и напоминания считаются по времени ученика. Сменить пояс можно командой `/tz`.

### ИИ (необязательно)
Если указать ключ GigaChat, материалы и планы генерирует нейросеть. Без ключа бот работает на встроенных шаблонах.

## Запуск на компьютере

### 1. Установите Python
Нужен Python 3.10 или новее: https://www.python.org/downloads/
При установке на Windows отметьте галочку **«Add Python to PATH»**.

### 2. Скачайте проект
```bash
git clone https://github.com/mxdkvs/school_helper_bot.git
cd school-helper-bot
```
Или скачайте ZIP на странице репозитория: кнопка **Code → Download ZIP**.

### 3. Установите библиотеки
```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
```

### 4. Добавьте сертификаты
Скачайте с https://www.gosuslugi.ru/crt сертификаты **Russian Trusted Root CA** и **Russian Trusted Sub CA** и положите их в папку `certs/`.
Без них сервер MAX не установит защищённое соединение.

### 5. Заполните `.env`
MAX_TOKEN=ваш_токен_бота


| Параметр | Обязательный | Описание |
|---|---|---|
| `MAX_TOKEN` | ✅ | токен бота MAX |
| `GIGACHAT_AUTH_KEY` | — | ключ GigaChat; без него используются шаблоны |
| `TZ_OFFSET` | — | часовой пояс по умолчанию (12 — Камчатка, 3 — Москва) |
| `PLAN_REMINDER_TIME` | — | время ежедневного напоминания (по умолчанию 15:30) |
| `DB_PATH` | — | путь к базе данных |

### 6. Запустите
```bash
python bot.py
```
Если в консоли появилась строка `Бот запущен`, всё работает. Найдите бота в MAX и нажмите «Начать».

## Запуск в Docker

Понадобится Docker Desktop: https://www.docker.com/products/docker-desktop/

### Готовый образ
При каждом обновлении репозитория GitHub Actions сам собирает образ и публикует его в GitHub Container Registry:
```bash
docker pull ghcr.io/mxdkvs/school_helper_bot:latest
docker run -d --name school-helper-bot --env-file .env -v ./data:/app/data --restart unless-stopped ghcr.io/mxdkvs/school_helper_bot:latest
```

### Сборка образа
```bash
docker build -t school-helper-bot .
```

### Запуск контейнера
```bash
docker run -d --name school-helper-bot --env-file .env -v ./data:/app/data --restart unless-stopped school-helper-bot
```
| Параметр | Зачем |
|---|---|
| `-d` | запуск в фоне |
| `--env-file .env` | передать токен и настройки; `.env` в образ не попадает |
| `-v ./data:/app/data` | хранить базу данных на компьютере, чтобы данные не пропадали |
| `--restart unless-stopped` | перезапускать бота после сбоя или перезагрузки |

Управление контейнером:
```bash
docker logs -f school-helper-bot     # логи
docker stop school-helper-bot        # остановить
docker start school-helper-bot       # запустить снова
docker rm -f school-helper-bot       # удалить контейнер
```

### Через docker compose
```bash
docker compose up -d --build     # собрать и запустить
docker compose logs -f           # логи
docker compose down              # остановить
```

## Как это работает

- Бот получает сообщения от MAX через **long polling** (`GET /updates`), поэтому сервер с белым IP не нужен.
- Каждый экран — **одно сообщение**: при нажатии кнопки бот меняет текст на месте, и чат не засоряется.
- Планы, дедлайны, проекты и напоминания хранятся в **SQLite**.
- Напоминания проверяются раз в 30 секунд в отдельном потоке.
- Для генерации текстов можно подключить **GigaChat API**.

**Технологии:** Python 3, requests, SQLite, MAX Bot API, GigaChat API, Docker, GitHub Actions.
